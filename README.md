# EmiratTravel — Web Application for Travel Company

A real-world full-stack web application developed as part of a university internship project for the travel company **Emirat Travel S.R.L**. The system allows administrators to manage travel offers, destinations, and other website content through an internal admin panel.

## 🚀 Features

- Admin panel for managing travel content (tours, destinations, media, etc.)
- User-friendly interface for clients to view travel offers
- Full CRUD functionality for content management
- Role-based access for secure content updates
- Clean architecture for maintainability and scalability

## 🛠️ Tech Stack

**Backend:**
- ASP.NET Core
- Entity Framework Core
- SQLite

**Frontend:**
- Razor Pages / MVC Views (ASP.NET)

**Tools:**
- Visual Studio
- Git & GitHub
- Postman (for API testing)
